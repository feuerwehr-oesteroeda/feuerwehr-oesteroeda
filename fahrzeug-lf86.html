Löschgruppenfahrzeug 8/6

Start Einsätze Fahrzeuge Über Uns

Verwendung

  • Das Löschgruppenfahrzeug 8/6 (LF 8/6) verfügt über einen eigenen Löschwasservorrat von 600 Litern, eine Schnellangriffseinrichtung, einen Schaummittelvorrat von 60 Litern und eine Feuerlöschkreiselpumpe mit einer Förderleistung von 800 Litern pro Minute bei 8 bar Ausgangsdruck. Zudem vefügt das LF 8/6 über einen hydraulischen Rettungssatz.
